# Architecture and review audit

Boundary: callers choose the fixed question/corpus, never its verdict. Sources
own actual published bytes. Contract fetches full pinned versions inside each
nondeterministic flow. Leader and validators each interpret every coalition.
The deterministic effect is signed marginal-contribution accounting with exact
integer conservation or explicit algebraic uncertainty intervals.

| Prior objection | Implemented boundary |
|---|---|
| Renamed versioned graph proposal | No graph, owner mutation, parent head or structural proposal; immutable game plus one terminal accounting record |
| Decorative nondeterminism | Changing a substantive coalition label changes point fractions/bounds and whether exact consumer access exists |
| Stored URL never fetched | Each validator fetches all full bodies; raw hashes and status/body commitments are independently checked |
| Self-reported delivery/alignment | No delivery/alignment claim is evaluated; no provider statement or annotation is authoritative |
| Hash-length or summary checks | Hash is byte binding only; actual document prose determines every coalition label |
| Tolerance crosses threshold | No tolerance; exact report/label equality and deterministic output derivation |
| Unknown approved as known | UNKNOWN stays a range; failed acquisition gives HELD with no attribution |
| Stale/replayed/cross-case report | Authenticated nonce namespace, input root and deployment/case binding; terminal resolution cannot be overwritten |

At most three sources mean seven nonempty coalitions and twelve subset-weighted
marginal terms. Full bodies are each <=5000 bytes, not silently truncated.
Output roots bind the complete consensus report and all computed fractions.

The implemented object is a document-contribution **game**, not an independent
claim certificate. EXACT means all coalition judgments are known under the model;
it does not mean those judgments are correct. No award/acceptance/novelty promise.
